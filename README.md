# metric.track — PWA

A lightweight daily metric tracker installable as an app on Android (and iOS) via GitHub Pages.

## Install on Android

1. Open the GitHub Pages URL in **Chrome**
2. Tap the **⋮ menu** → **"Add to Home screen"**
3. Tap **Add** — it appears on your home screen like a native app
4. Opens full-screen with no browser UI, works offline

## Features

- Add/remove custom metrics
- Large +/− tap buttons per metric
- Counts persist in `localStorage` (survive tab close / refresh)
- Per-day storage — browse history with ◀ ▶ arrows
- Reset counts for any day
- Export all data as CSV
- Works fully offline after first load (service worker)
